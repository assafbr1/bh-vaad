# סקריפטי Apps Script של דאשבורד ועד בית חורון

עותקי הקוד שמותקן בפרויקטי Apps Script. כל עדכון שנמסר לאסף נשמר כאן באותה גרסה, כך שאין צורך להעתיק את הקוד מהפרויקט לפני עדכון.

- `registration.gs`: "סקריפט הרישום ועד בית חורון" (קובץ יחיד, מחליף את כל הקוד). גרסה 3.1, 28.9.2026.
- `bakara.gs`: קובץ נפרד בפרויקט "סקריפט הקליטה ועד בית חורון" (בקרת תקינות, גרסה 1.4, 28.9.2026).
- `intake.gs`: "סקריפט הקליטה ועד בית חורון", הקובץ הראשי (קוד.gs). יתווסף כשאסף ימסור עותק.

הקבצים אינם מכילים קודי כניסה או סודות; מזהי הגיליונות וכתובת המייל מופיעים גם בסקיל.
