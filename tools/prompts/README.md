# הנחיות הריצות המתוזמנות

עותקים של ההנחיות (prompt) של המשימות המתוזמנות של דאשבורד ועד בית חורון, כפי שנמסרו למערכת התזמון. כל עדכון להנחיה נכתב קודם כאן ואז נמסר ב-update_trigger.

- `nightly.txt`: ריצת הלילה (trig_013UAJrhooePr18Cy6qGiedx, 01:30 UTC כל יום).
- `midday.txt`: ריצת הצהריים (trig_0121aGW2w3xDkjRyyH1p84oX, 09:00 UTC ימים א' עד ה').
- `backup.txt`: גיבוי בסיס הנתונים לדרייב (trig_015SgfVr12nQQHP6Uk2gESoh, 05:35 שעון ישראל כל יום; גיבוי מלא אחת לחודש וגיבוי יומי של הפרשים).

עדכון אחרון: 29.9.2026 (גרסה 1.6: מקור ותאריך המידע, כלל "החדש קודם" בוואטסאפ, בקרת תקינות מדויקת יותר).

פרסום האתר (מ-29.9.2026 בצהריים): הריצה דוחפת את `keys.json` ואת החלקים `data.enc.part-NN.txt` (פרוסות של 30,000 תווים; `data.enc.txt` המלא גדול מדי לקריאת push_files אחת) לענף `build-YYYYMMDD-night` או `build-YYYYMMDD-midday` (לא ל-`main`). הפעולה `.github/workflows/publish-build.yml` מאחה את החלקים ל-`data.enc.txt`, מעתיקה את `data.enc.txt` ו-`keys.json` ל-`main`, סוגרת PR אם נפתח ומוחקת את הענף. הסיבה: מנגנון הבטיחות של הריצות המתוזמנות חוסם דחיפה ישירה ל-`main` (נחסם ב-29.9 בלילה ובצהריים).
