# הנחיות הריצות המתוזמנות

עותקים של ההנחיות (prompt) של המשימות המתוזמנות של דאשבורד ועד בית חורון, כפי שנמסרו למערכת התזמון. כל עדכון להנחיה נכתב קודם כאן ואז נמסר ב-update_trigger.

- `nightly.txt`: ריצת הלילה (trig_013UAJrhooePr18Cy6qGiedx, 01:30 UTC כל יום).
- `midday.txt`: ריצת הצהריים (trig_0121aGW2w3xDkjRyyH1p84oX, 09:00 UTC ימים א' עד ה').
- `backup.txt`: גיבוי בסיס הנתונים לדרייב (trig_015SgfVr12nQQHP6Uk2gESoh, 05:35 שעון ישראל כל יום; גיבוי מלא אחת לחודש וגיבוי יומי של הפרשים).

עדכון אחרון: 2.10.2026 (גרסה 1.8: משתתפים חיצוניים: אוסף participants בחבילה, דיווחים מאתר המשתתפים (מזהה p-, byKind guest, visibleTo ['*']), כניסות משתתפים מיומן הכניסות, דחיפת guestkeys.json ו-guests/*.enc.txt לענף הבנייה, ציון דיווחי משתתפים ומשתתפים ללא דיווח 14 יום בפוש). קודם: 2.10.2026 גרסה 1.7 (addedAt, הצעות לסדר היום, lastLoginAt וסדר יום בחבילה); 29.9.2026 גרסה 1.6.

פרסום האתר (מ-29.9.2026 בצהריים): הריצה דוחפת את `keys.json` ואת החלקים `data.enc.part-NN.txt` (פרוסות של 30,000 תווים; `data.enc.txt` המלא גדול מדי לקריאת push_files אחת) לענף `build-YYYYMMDD-night` או `build-YYYYMMDD-midday` (לא ל-`main`). הפעולה `.github/workflows/publish-build.yml` מאחה את החלקים ל-`data.enc.txt`, מעתיקה את `data.enc.txt`, `keys.json`, ומגרסה 1.8 גם `guestkeys.json` ו-`guests/*.enc.txt` (ומוחקת קובצי משתתפים שאינם ב-`guestkeys.json`) ל-`main`, סוגרת PR אם נפתח ומוחקת את הענף. הסיבה: מנגנון הבטיחות של הריצות המתוזמנות חוסם דחיפה ישירה ל-`main` (נחסם ב-29.9 בלילה ובצהריים).
