# הנחיות הריצות המתוזמנות

ההנחיות (prompt) של המשימות המתוזמנות של דאשבורד ועד בית חורון.

מבנה מ-13.10.2026 (הנחיה מקוצרת): ההנחיה השמורה במשימות הלילה והצהריים היא קצרה (`boot-nightly.txt`, `boot-midday.txt`). היא מורה לריצה לטעון את ההוראות המלאות מ-`nightly.txt` או `midday.txt` בענף main, ולפעול רק אם ה-git hash-object של הקובץ זהה ל-sha שכתוב בהנחיה המקוצרת ואם הקובץ מסתיים בשורת "שם המשימה לצורך ההתראה". הסיבה: את הנוסח השמור במשימה אי אפשר עוד לקרוא לקובץ ולאמת אותו תו בתו, ואת הקובץ בריפו אפשר לאמת מכנית לפי ה-sha.

שינוי בהוראות של ריצה: (1) עורכים את `nightly.txt` או `midday.txt` כאן ודוחפים ל-main; (2) מחשבים את ה-git hash-object החדש; (3) מעדכנים את ה-sha (בשני המקומות שבהם הוא מופיע) ב-`boot-*.txt` המתאים ודוחפים; (4) שולחים ב-update_trigger את הטקסט המלא של `boot-*.txt`. בלי שלב 4, הריצה הבאה תיכשל בכוונה ותתריע ("ההוראות בריפו אינן תואמות לגרסה המאושרת"). אין לשלוח ב-update_trigger את `nightly.txt` או `midday.txt` המלאים.
